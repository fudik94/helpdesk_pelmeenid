## Overview

Terminal-based service desk ticket management system demonstrating an "existing codebase" scenario. Simulates a real-world help desk environment with priority-based SLA tracking, escalation workflows, and team workload distribution.

---

## Key Features

- ✅ **Ticket Management**: Create, view, assign, and close tickets
- 👤 **Assignment & Workflow**: Assign to staff, add comments, escalate/de-escalate
- ⏱️ **SLA Monitoring**: Automatic tracking with visual status badges (OK/YELLOW/RED)
- 📊 **Dashboard**: Statistics on tickets, categories, and staff workload
- 📥 **CSV Export**: Generate reports for external analysis
- 🔐 **Role-based Access**: Admin and Support user roles
